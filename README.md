# Neon Flip

Full-colour Python 3 neon pinball arcade for ElbowOS.

Flip the neon paddles to keep the ball alive. Hit cyan, magenta, gold and lime bumpers. Score big on magenta targets. Don't drain.

**Controls:** A / Left flip left, D / Right flip right, Esc quit.

## Play
```
pip install -r requirements.txt
python3 neon_flip.py --play
```

## Record a 9:16 reel
```
python3 neon_flip.py --record
```
Writes `NEON_FLIP_ElbowOS.mp4` (1080x1920 h264, 15s @ 30fps) with title, score, and `x.com/ElbowOS` burned in.
